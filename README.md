# Fase 4 Componente Practico
Hacer un sistema orientado a objetos
que incluya clases abstractas
sin base de datos capaz de gestionar clientes
servicios y reservas para una empresa
manejo solido de excepciones en el que se incluyan excepciones personalizadas con encadenamiento de excepciones
registrar errores en un archivo de logs
sistema capaz de manejar errores provenientes del sistema
- clase abstracta que represente las entidades generales en el sistemas
- clase cliente con validaciones robustas y encapsualcion de datos personales
- clase abstracta servicio con al menos 3 servicios especializados heredados de ella, con polimorfismo y métodos sobrescritos para calcular costos, describir servicios y validar parámetros
- clase reserva que integre cliente, servicio, duración y estado, e implemente confirmación, cancelación y procesamiento con manejo de excepciones
- metodos sobrecargados
